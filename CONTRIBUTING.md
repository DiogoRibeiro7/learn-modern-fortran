# CONTRIBUTING

Thank you for contributing.

## What this repository values

This project is not only about code that works. It is about code that teaches.

A good contribution is:

- correct
- readable
- small enough to study
- clearly connected to a lesson or exercise
- aligned with modern Fortran practice

## Before opening a change

Please check:

- does this belong in `lessons/`, `examples/`, `exercises/`, or `projects/`?
- is the content appropriate for the learner level?
- does the code use modern style?
- is there a simpler way to teach the same idea?

## Suggested workflow

1. pick one topic
2. update the lesson content
3. add or update a runnable example
4. add or update exercises
5. run the example locally
6. add tests if reusable logic is introduced

## Formatting and style

- use free-form Fortran source
- use `implicit none`
- keep indentation consistent
- prefer clear names over short names
- document tricky numerical assumptions
- follow [docs/style-guide.md](docs/style-guide.md) for code, lesson, and exercise conventions

## Issues

Good issue types include:

- lesson expansion
- bug in example code
- missing exercise solution
- clarity problem in explanation
- missing tests for numerical behavior
