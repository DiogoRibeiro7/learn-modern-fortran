# Lesson 09 — Legacy to modern

## Why this lesson matters

Many real Fortran codebases are old. You should be able to read them without adopting their weakest habits as your defaults.

## What you should learn

- what fixed-form code looks like
- common legacy patterns
- how to refactor step by step

## Main ideas

- preserve behavior first
- modernize structure gradually
- replace global patterns with modules and explicit interfaces

## Suggested practice

- rewrite one legacy-style routine into a module-based version
- identify hidden assumptions in old code

## Suggested next step

Return to the projects and extend them.
