# Lesson 06 — Testing with fpm

## Why this lesson matters

Testing turns examples into maintainable projects. Numerical code also benefits from explicit checks.

## What you should learn

- how `fpm test` works
- how to structure a simple test target
- how to compare floating-point results carefully

## Main ideas

- test reusable logic, not print statements
- prefer tolerances for real numbers
- keep tests small and specific

## Suggested practice

- run `fpm test` in `examples/vector-ops`
- add a test for a dot product function
