# Lesson 01 — Setup

## Why this lesson matters

A clean toolchain removes friction early. Fortran becomes much easier to learn when compilation, package management, and editor support are already working.

## What you should learn

- what compiler you need
- why `fpm` matters
- how to verify your environment
- how to run your first example

## Main ideas

- install a compiler first
- confirm `fpm --version`
- use a modern editor setup
- test with a tiny program immediately

## Suggested practice

- run the `examples/hello-fpm` project
- change the printed message
- rebuild and rerun
