# Lesson 02 — Basics

## Why this lesson matters

These are the building blocks of every Fortran program: variables, types, expressions, control flow, and output.

## What you should learn

- variable declarations
- numeric and logical types
- control flow
- simple input and output

## Main ideas

- declare before use
- use `implicit none`
- learn `if`, `do`, and simple expressions
- keep programs small at first

## Suggested practice

- create a temperature converter
- write a program that classifies a number as positive, negative, or zero
