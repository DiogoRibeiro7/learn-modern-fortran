# Lesson 03 — Arrays and procedures

## Why this lesson matters

Arrays are central in scientific computing, and procedures are how you stop repeating yourself.

## What you should learn

- array creation and slicing
- intrinsic functions like `sum` and `size`
- functions vs subroutines
- intent declarations

## Main ideas

- arrays are first-class tools in Fortran
- procedures improve structure
- intent makes procedure contracts clearer

## Suggested practice

- compute the mean of a vector
- write a function for the Euclidean norm of a vector
