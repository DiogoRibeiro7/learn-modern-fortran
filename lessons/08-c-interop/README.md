# Lesson 08 — C interoperability

## Why this lesson matters

Fortran often lives inside larger systems. Knowing the boundary with C helps you integrate old and new components.

## What you should learn

- the purpose of `iso_c_binding`
- how to think about data layout across languages
- when interop is useful

## Main ideas

- interop is powerful, but it needs careful interfaces
- keep the first examples very small
- understand scalars before arrays

## Suggested practice

- write down the interface of a tiny C-style function before implementing it
