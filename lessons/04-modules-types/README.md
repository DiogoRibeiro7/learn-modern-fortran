# Lesson 04 — Modules and derived types

## Why this lesson matters

Real codebases need reusable structure. Modules and types are how modern Fortran organizes logic and data.

## What you should learn

- creating modules
- importing with `use`
- controlling visibility
- defining derived types

## Main ideas

- keep logic in modules
- keep `program` files thin
- use `private` and `public` intentionally
- derived types group related data cleanly

## Suggested practice

- turn a loose function into a module
- define a `point2d` type with `x` and `y` components
