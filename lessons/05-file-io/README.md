# Lesson 05 — File I/O

## Why this lesson matters

Scientific and engineering programs often read measurements, parameters, and simulation outputs from files.

## What you should learn

- opening files
- reading line-based and structured data
- writing results safely
- basic status handling

## Main ideas

- check whether files open correctly
- separate I/O from computation when possible
- keep text formats simple for learning

## Suggested practice

- read a list of numbers from a text file
- compute a summary and write it to an output file
