# Lesson 07 — Numerical mini-projects

## Why this lesson matters

This is where syntax starts turning into applied scientific programming.

## What you should learn

- how to translate a numerical idea into a structured program
- how to break a small problem into modules and drivers
- how to validate numerical results

## Main ideas

- start with simple numerical methods
- test on small known cases
- document assumptions and formulas

## Suggested practice

- estimate pi with Monte Carlo
- solve a simple ODE with Euler's method
- compute row and column summaries for a matrix
