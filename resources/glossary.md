# Glossary

## free-form source
Modern source layout where spacing and columns are not constrained by the old fixed-format rules.

## fixed-form source
Older Fortran source format with column-based rules. Important for reading legacy code, but not the default style for new projects.

## module
A unit used to organize reusable procedures, types, and constants.

## derived type
A user-defined data structure.

## kind
A way to specify a numeric representation, such as a chosen integer or real precision.

## array slice
A view over a part of an array, such as `x(2:5)`.

## elemental procedure
A procedure that can act element-wise over arrays.

## pure procedure
A procedure with restricted side effects, helpful for clearer reasoning and optimization.

## `fpm`
Fortran Package Manager. A build and package tool for modern Fortran projects.
