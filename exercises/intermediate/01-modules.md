# Intermediate exercises — modules and reusable code

## Exercise 1
Create a module named `stats_utils` with a function that computes the mean of a real vector.

## Exercise 2
Extend the module with a function for the population variance.

## Exercise 3
Create a small `program` that imports the module and prints both values for a test vector.

## Exercise 4
Add a test target using `fpm` and check the mean and variance on a small case.

## Reflection
What became clearer after moving logic from the main program into a module?
