# Beginner exercises — basics

## Exercise 1
Write a program that reads a radius and prints the area of a circle.

## Exercise 2
Write a program that receives an integer and tells whether it is:

- positive
- negative
- zero

## Exercise 3
Create a vector of five real values and print:

- the sum
- the average
- the maximum value

## Exercise 4
Write a loop that prints the first ten squares.

## Reflection
Which parts of the language felt similar to Python, C, or MATLAB, and which felt different?
